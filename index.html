Welcome

This is a personal body-mapping tool. Tap the body to drop a pin, add a photo, and track it over time.

Important: All your data lives in this browser only. Because you're running from a local file, the browser may clear it without warning. Export a backup (Settings → Export) regularly, and consider hosting this as a PWA when you're ready — see README.md.
